Problem Statement: Merge and Sort Integer Arrays
Problem Description:

Write a function that takes two arrays of integers, merges them into a single array, and sorts the resulting array in ascending order without any duplicates.

Input:

Two lists of integers ( {arr1} ) and ( {arr2} ) (1 ≤ length of ( {arr1} ), ( {arr2} ) ≤ 1000), where each integer ( {arr}[i] ) (−10^6 ≤ ( {arr}[i] ) ≤ 10^6).
Output:

Print the merged and sorted list of integers in ascending order without duplicates.
Examples:

Input:
arr1 = [1, 3, 5, 7]
arr2 = [2, 3, 6, 8]

Output:
[1, 2, 3, 5, 6, 7, 8]
Input:
arr1 = [10, 20, 30]
arr2 = [20, 40, 50]

Output:
[10, 20, 30, 40, 50]

Explanation:

In the first example, the arrays [1, 3, 5, 7] and [2, 3, 6, 8] are merged and sorted in ascending order, with duplicates removed.
In the second example, the arrays [10, 20, 30] and [20, 40, 50] are merged and sorted in ascending order, with duplicates removed.
Constraints:

The input arrays will have lengths within the specified range.
Each integer in the arrays will be within the specified range.
