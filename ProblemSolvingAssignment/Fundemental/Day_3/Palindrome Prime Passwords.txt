Problem Statement: Palindrome Prime Passwords

Problem Description:

In a futuristic security system, passwords are generated using palindrome primes. A palindrome prime is a prime number that reads the same backward as forward. For example, 131 and 151 are palindrome primes.

Given a range of integers, your task is to find all palindrome primes within that range. These numbers will be used to generate secure passwords for the system.

Input:

The first line contains an integer (L) (1 ≤ (L) ≤ (10^6)), representing the lower bound of the range.
The second line contains an integer (R) (1 ≤ (R) ≤ (10^6)), representing the upper bound of the range.
Output:

Print all palindrome primes within the range ([L, R]). Each number should be printed on a new line.
If there are no palindrome primes in the given range, print "No palindrome primes found".
Example:

Input:
100
200

Output:
101
131
151
181
191

Explanation:

Within the range 100 to 200, the palindrome primes are 101, 131, 151, 181, and 191.
Note:

Ensure your solution is efficient and can handle the upper limits of the input constraints.
