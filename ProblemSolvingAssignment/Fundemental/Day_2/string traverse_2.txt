Given a string, write a function to traverse the string and perform the following operations:

Print each character of the string along with its frequency.
Identify and return the first non-repeating character in the string.
Identify and return the first repeating character in the string.
Example:

Input: str = "swiss"

Output:

Characters and their frequencies:
s: 3
w: 1
i: 1
First non-repeating character: w
First repeating character: s
